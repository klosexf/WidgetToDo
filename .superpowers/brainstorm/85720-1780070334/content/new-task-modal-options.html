新建任务弹窗视觉方向

都保持现有功能和交互不变，只比较它如何并入主界面的卡片语言。你已经选了“更贴近主界面卡片风格”，所以下面是这个方向下的 3 个强弱版本。

Option A
+ 新建任务
日期
Esc 取消Enter 创建

嵌入式浮层

最贴近当前待办面板。像从任务列表里长出来的一张卡，而不是独立 modal。改动克制，风险最低。

Option B
+ 新建任务
Esc 取消创建

工具条式编辑卡

更紧凑，输入和日期并排，更像主界面里的快速编辑器。信息密度高，但仍保留明显的提交区。

Option C
+ 新建任务
日期
取消创建任务

完整卡片面板

层次最完整，像一个 mini panel 放进主面板里。视觉更稳，但比现有交互显得更“重”。
